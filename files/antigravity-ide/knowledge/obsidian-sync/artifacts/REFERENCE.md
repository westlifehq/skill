# 📖 obsidian-sync 路由、命名与 Frontmatter 参考规范

本文件作为 `obsidian-sync` 的快速查阅手册与规则比对标准，供技能引擎和开发人员复核校验使用。

---

## 1. 📂 路由分配对照表

| 📁 目标目录 (由根目录出发) | 🏷️ 匹配关键词 / 特征语义 | 🛠️ 处理方式 |
| :--- | :--- | :--- |
| **`/30 会议与事件/`** | `会议` `周报` `复盘` `故障` `讨论` `周会` `故障报告` | 自动创建 `YYYY-MM-DD · 标题.md` 笔记。 |
| **`/10 项目/{项目名}/`** | `dyvideo` `iot` `router` `kindle` `za` 等，且明确属于项目迭代、状态刷新 | 自动检测并进入子文件夹 `{项目名}`，同主题增量更新使用 `## 更新` 追加。 |
| **`/20 知识库/`** | `SOP` `部署流程` `原理` `设计方案` `概念梳理` `调研报告` | 新建标准技术总结或指南文档。 |
| **`/99 附件与源文件/`** | `.html` 文件、原始飞书文档、图片及音视频等多媒体源资产 | 物理转移/复制到该目录，主笔记中采用 `![[附件名]]` 或相对路径关联。 |
| **`/AI 收件箱/`** | 无法做出精细分类、归属模糊、概念交叉的泛类草稿 | 落入此滑口，且必须在 Frontmatter 中追加 `needs_triage: true` 标记。 |

## 2. 📛 命名与安全过滤规范
- **文件名模板**：`YYYY-MM-DD · 简要标题.md`（中间使用空格加圆点 ` · ` 拼接，保证美学统一）。
- **去重防盖机制**：如果同天同名，后缀累加 `-2`, `-3`，如 `2026-05-28 · PVE配置SOP-2.md`。
- **非法字符清洗**：强制通过正则替换文件名中的非法字符：
  ```javascript
  const sanitizedTitle = rawTitle.replace(/[\\\/:*?"<>|]/g, "_");
  ```

## 3. 📋 标准 Frontmatter YAML 模板
所有被本技能同步写入的笔记，**必须**包含以下标准元数据，严禁缺少任何一项：

```yaml
---
title: 提取出的简要文档标题
created: YYYY-MM-DDTHH:mm:ss+08:00 (严格采用本地 ISO 8601 格式)
source: ai
source_skill: 调用本同步技能的父技能名称 (例如 summary-html，若无调用者则填 ad-hoc)
related:
  - 关联的 HTML 本地物理相对路径 (例如 ../99 附件与源文件/2026-05-28 · xxx.html，如有)
  - 飞书文档在线 URL 链接 (如有)
tags: [ai-generated, 智能提取标签1, 智能提取标签2, 智能提取标签3]
---
```

## 4. 🚫 反例与禁忌 (Strict Taboos)
为了防止 Obsidian 被无价值的“信息垃圾”污染，**下列场景下绝对禁止触发文件同步与创建操作**：

1. **聊天与社交寒暄**：
   - *“你好”*、*“今天天气真好”*、*“谢谢你”*、*“没关系”* 等无任何实质技术增量的日常打招呼或客套语。
2. **纯调试信息与命令报错输出**：
   - 执行 `npm install` 失败后的控制台日志、单纯的报错堆栈复述（例如 `ENOENT: no such file...`）、或者临时跑的 `ls -la` 物理输出结果。
3. **单句或极其琐碎的问答**：
   - 比如用户问 *“我的 IP 是多少”*，AI 答 *“您的 IP 是 192.168.31.1”*。这种不超过 100 字、随问随忘的 Ad-hoc 琐碎数据绝对不值得归档。
4. **代码草稿调试片段**：
   - 临时写给用户看的一个 10 行 JavaScript `for` 循环测试脚本，或者一个一过性的一行 Linux 命令等。
