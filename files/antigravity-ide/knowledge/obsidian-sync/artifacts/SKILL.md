# 🤖 obsidian-sync 技能主入口

本技能用于在 AI 助手产出高价值结构化总结、会议纪要、调研报告、飞书文档或 HTML 总结时，**全自动将一份高保真的纯 Markdown 镜像以严格的路由、命名和交叉引用规范同步写入到本地的 Obsidian Vault 中**，确保本地知识体系零人工损耗、完美聚合。

---

## 1. 🎯 触发时机与调用机制

### 1.1 显式调用
- 被其他技能（如 `feishu-summary`、`summary-html` 等）在产出最终文件后作为后置动作显式调用。

### 1.2 主动探针加载
当 AI 助手检测到当前的任务对话具备下列特征之一时，必须主动加载并启动本技能：
1. **内容规模**：输出是一份总字数超过 **300字** 的结构化总结、调研报告、架构梳理或长篇学习笔记。
2. **明确指示**：用户输入中明确包含 `“保存”`、`“存档”`、`“入库”`、`“记录下来”` 等强归档意图的关键词。
3. **伴生产物**：输出在当前会话中被同步要求导出为 `.html` 网页或飞书（Lark）云文档。
*⚠️ **调试型输出、代码片段单答、闲聊问答或错误复述等纯临时、低信息价值产物严禁触发本技能**。*

---

## 2. 📝 内容同步与格式生成标准

### 2.1 格式纯净化
- 仅提取和保留**高可读性纯 Markdown 净内容**。
- **严禁**嵌入 Base64 原始大体积图片字符，**严禁**保留未经转译的原始 HTML 大段标签（支持过滤为标清 Markdown 语法）。

### 2.2 伴生产物锚定
- 如果存在配套的 HTML 总结或飞书云文档镜像，必须在 Markdown 正文的最末尾自动追加 `## 🔗 相关产物` 专属小节，清晰列出它们在本地的相对物理路径或云端 URL，实现双流咬合。

### 2.3 智能标签提取
- AI 必须从最终整理的文章主体中智能提取 **3 到 8 个** 精准关键词，转化为 yaml 数组并作为 `tags` 写入头部。

---

## 3. 📂 严格的路由分配法则
技能必须对产出文档进行多轮特征比对，智能推送到以下专属知识大类中：

| 🎯 目标归属目录 | 📑 判定匹配规则 |
| :--- | :--- |
| **`/30 会议与事件/`** | 包含会议纪要、开发讨论、周报整理、事件复盘及突发网络故障排查报告等。 |
| **`/10 项目/{项目名称}/`** | 明确属于某一具体项目（如 `dyvideo`, `iot`, `router`, `kindle`, `za`）的上下文、状态同步或重构文档。*（AI 负责自动创建项目对应的英文/拼音子文件夹）* |
| **`/20 知识库/`** | 主题性技术知识点、概念深度梳理、新技术的调研方案与部署 SOP 指南。 |
| **`/99 附件与源文件/`** | 原始的 `.html` 镜像或飞书格式的导出源文件，主 Markdown 可使用相对路径直接引用或关联。 |
| **`/AI 收件箱/`** | 无法做出精准分类、语义混淆的泛类文档。此时必须在 Frontmatter 中自动追加 `needs_triage: true` 标记。 |

---

## 4. 📛 严苛的文件命名规范
- **文件名标准模板**：`YYYY-MM-DD · 简要标题.md`
- **重名防写覆盖机制**：
  - 写入前，AI 必须使用 `search` 对库内同名文件进行预先嗅探。
  - 若在同一天发生了同名文件多次创建，严禁直接覆盖原文件！必须自动追加 `-2`, `-3` 等后缀进行防重防写保障。
- **非法字符净化**：强制剔除文件名中的 `\`, `/`, `:`, `*`, `?`, `"`, `<`, `>`, `|` 等系统非法或保留字符。

---

## 5. 🔄 智能去重与增量更新
- **同主题判定**：若检测到是对同一项目、同一主题的**增量状态更新**（而非全新独立的笔记），**严禁创建冗余的新 md 文件**！
- **增量追加**：AI 必须使用接口读取原有笔记内容，在文章尾部自动追加 `## YYYY-MM-DD 更新` 专属标题，并将增量上下文追加其下，保持单篇文档的生命周期完整性。

---

## 6. 🔗 双向链接与 MOC 交叉引用
- **库内交叉互连**：利用 search 工具查询库内已存有的相关主题笔记。若当前生成内容提及它们，必须自动转化为 `[[关联笔记名称]]` 的 Wiki 双向链接语法。
- **目录索引自动追加 (MOC)**：
  - 在每一次成功同步后，AI 必须读取该路由目录下的 `_index.md` 文件。
  - 在其 `_index.md` 索引的尾部（或指定区域）以规范格式自动追加一行引用标记：
    `- [[文件名|标题]] · YYYY-MM-DD`

---

## 7. 🚨 错误处理与高可用容灾
- **服务不可用兜底**：若检测到本地 Obsidian REST API 插件未启动、端口冲突或连通性彻底故障时，**严禁静默失败**！
- **回马枪提示**：AI 必须在当前会话的交付物尾部强力渲染一个极其显眼的警示框：
  > [!WARNING]
  > **Obsidian 同步未完成**
  > **原因**：[此处填入具体的端口超时/拒绝连接/未授权错误信息]
  > **备选方案**：您可以手动复制以下完整 Markdown 并在 Obsidian 中保存落盘：
  > [完整 Markdown 块文本]
- **重试恢复**：对于偶然性权限/超时错误，系统支持最多 **2 次** 间隔自动重试。
